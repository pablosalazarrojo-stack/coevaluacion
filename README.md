# coevaluación

App para que los alumnos de la clase evalúen a los equipos que presentan (6 dimensiones, sliders de 0 a 100). Cada alumno entra con su matrícula, no ve a su propio equipo y envía todas sus calificaciones al final.

- `index.html`: la página (GitHub Pages). No guarda matrículas ni nombres.
- `Code.gs`: el script de Google que guarda las respuestas en una hoja privada. La lista de alumnos y la contraseña del profe solo viven en el editor de Apps Script.
